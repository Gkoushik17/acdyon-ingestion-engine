Architecture & System Design Documentation

1. Detection Surface (How Automated Clients Get Caught)

  • TLS/JA3 & HTTP/2 Fingerprints: Standard scrapers use default OpenSSL/Python ciphers easily identifiable by Akamai/Cloudflare. Solved via modern header ordering and connection profile matching.
  • Request Cadence & Timing: Fixed interval requests (e.g. exactly every 1000ms) betray robotic actors. Solved via token-bucket exponential backoff + uniform jitter.
  • Missing Client Hints: Omitting Sec-CH-UA, Sec-Fetch-Dest, and realistic Accept-Language headers immediately flags requests.

2. Ingestion Strategy & Plan B

  • Circuit Breaker: Trips to OPEN upon receiving 429 or 403 responses to prevent IP reputation destruction.
  • Multi-Source Failover: If the primary origin throttles or breaks, requests automatically switch to fallback public feeds.
  • Plan B Architecture: Decoupled parsers and intermediate SQLite storage ensure consumer services remain operable even if primary providers alter markup.

3. Resilience Against Markup Drift

  • Zero Silent Failures: Pydantic models validate required fields (title, company, url).
  • Drift Telemetry: Unparseable items generate a SchemaDriftReport logged directly to the telemetry database without aborting valid sibling records.

4. Ethical & ToS Line

This pipeline strictly adheres to the scope guardrails by targeting public RSS feeds, authorized APIs, and sandbox endpoints. It respects robots.txt directives and backs off completely when rate limit signals are emitted.
